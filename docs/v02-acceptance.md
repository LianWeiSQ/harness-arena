## 最终收尾顺序

1. 核对每组实验的协议、模型、镜像、资产与任务哈希，开发/验证覆盖、加载、已知/未知用量和资源清理。
2. 按预登记规则选择候选或初始版本；无效实验停止，保留失败原因。不得为取得提升更换候选或改判定门槛。
3. 执行独立封存；同一最终版本共用一份报告时明确标记，不把重复波动归为进化收益。
4. 发布脱敏组合报告与真实回放，更新 M3/M6、架构边界、面试说明；按改动验证工作台与独立安装。
5. 复核本台账全部条件，提交推送并核对远端。只有这些完成后才能将 Goal 设为 complete。

v0.3/v0.4 的记忆、检索、模型路由、工具、工作流、协作与训练数据导出仍在 [能力地图](evo-platform-plan.md#能力地图) 和 [扩展指南](extensions.md) 中，不自动加入 v0.2 完成范围。
